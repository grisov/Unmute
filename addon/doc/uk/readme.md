# NVDA Unmute (Автоувімкнення звуку Windows)

* Автор: Олександр Грищенко
* Версія: 1.8
* Сумісність з NVDA: 2026.1 та новіші версії
* Встановлення: через Магазин додатків NVDA ([стабільна версія][1])

Будьте певні, що чуєте NVDA: під час запуску NVDA додаток вмикає приглушений або занадто тихий звук Windows і NVDA та запускає синтезатор мовлення, якщо той не запустився. Ті самі перевірки можна будь-коли виконати командою.

## Коли працює додаток
* Під час запуску NVDA. Це можна вимкнути опцією "Вмикати звук під час запуску NVDA" в налаштуваннях додатку.
* Будь-коли за командою "Увімкнути звук Windows і NVDA". Команду наведено в діалозі NVDA "Жести вводу", у категорії "Автоувімкнення звуку Windows". Там ви можете призначити їй власну комбінацію клавіш або увімкнути передвстановлену комбінацію NVDA+Windows+Shift+U опцією "Використовувати комбінацію клавіш за замовчуванням" в налаштуваннях додатку.

Після команди додаток завжди відтворює короткий звук, тож ви знаєте, що вона спрацювала, навіть якщо раніше нічого не чули. Під час запуску NVDA звук відтворюється лише тоді, коли щось було увімкнено.

## Що перевіряє додаток
Усе описане нижче виконується лише тоді, коли це увімкнено в налаштуваннях додатку. Звук вважається занадто тихим, якщо його гучність нижча за значення "Збільшувати гучність, якщо вона нижча ніж"; тоді його гучність піднімається до значення "Встановити власне значення рівня гучності", але ніколи не нижче мінімального рівня.

1. Режим мовлення: якщо мовлення NVDA вимкнено, замінено сигналами або увімкнено на вимогу, воно перемикається в режим "мовлення". NVDA завжди запускається в режимі "мовлення", тож це важливо переважно для команди.
2. Синтезатор: якщо жоден синтезатор не запустився, додаток намагається запустити синтезатор, вибраний у налаштуваннях NVDA, раз на секунду, стільки разів, скільки встановлено.
3. Пристрій виводу: NVDA перемикається на основний пристрій виводу Windows, тож звук вмикається там, де NVDA його відтворює.
4. Аудіопристрої Windows: з основного пристрою виводу Windows знімається приглушення, а його занадто тиха гучність піднімається. Якщо NVDA використовує певний пристрій виводу і не перемикається на основний, перевіряється і цей пристрій. Також можна піднімати кожен приглушений або занадто тихий канал пристрою, наприклад після того, як баланс зміщено в один бік; інші канали не змінюються.
5. Сама NVDA: зі звуку NVDA знімається приглушення, а його занадто тиха гучність піднімається на всіх активних пристроях виводу, бо Windows зберігає гучність програми окремо для кожного пристрою. Змінюється лише запущена копія NVDA, а не інша, наприклад портативна. Додаток також може відновлювати приглушені канали NVDA, піднімати занадто тиху гучність голосу синтезатора і занадто тиху гучність звуків NVDA.

Якщо служба звуку Windows ще запускається після входу в систему, додаток повторює спроби протягом кількох секунд.

Коли в налаштуваннях NVDA вибрано певний пристрій виводу, NVDA перемикається на основний пристрій під час кожного запуску, і щоразу відтворюється короткий звук. Щоб цього уникнути, збережіть конфігурацію NVDA після перемикання (NVDA+Control+C) або вимкніть опцію "Перемикати вивід звуку NVDA на аудіопристрій за замовчуванням".

## Дзвінки
Коли програма зв'язку починає дзвінок, Windows за замовчуванням зменшує гучність інших звуків на 80%, зокрема і NVDA. Опція "Не зменшувати гучність NVDA під час дзвінків" зберігає гучність NVDA незмінною. Вона стосується лише процесу NVDA: налаштування зв'язку Windows лишаються тими самими, а звук інших програм під час дзвінків і далі зменшується.

## Налаштування додатку
Щоб відкрити налаштування, відкрийте меню NVDA (NVDA+N), перейдіть до "Параметри", "Налаштування..." і виберіть категорію "Автоувімкнення звуку Windows". Налаштування зберігаються в базовому профілі конфігурації NVDA і діють одразу, без перезапуску NVDA.

* Вмикати звук під час запуску NVDA - виконувати все, що увімкнено нижче, під час запуску NVDA; інакше лише за командою. Типово увімкнено.
* Гучність:
    * Встановити власне значення рівня гучності - гучність, яка встановлюється для занадто тихого аудіопристрою, NVDA, її голосу або її звуків.
    * Збільшувати гучність, якщо вона нижча ніж - мінімальний рівень: нижча гучність піднімається.
* Аудіопристрої Windows:
    * Перемикати вивід звуку NVDA на аудіопристрій за замовчуванням - перемикати NVDA на основний пристрій виводу Windows. Типово увімкнено.
    * Вмикати приглушені канали аудіопристроїв - піднімати кожен занадто тихий канал аудіопристроїв. Типово вимкнено.
* Програма екранного доступу:
    * Вмикати приглушені канали NVDA - якщо будь-який канал NVDA занадто тихий, встановлювати всім каналам NVDA повний рівень, як це робить NVDA, коли вимикається розділення звуку. Недоступно, коли в NVDA увімкнено розділення звуку, бо розділення звуку саме встановлює рівні каналів. Типово вимкнено.
    * Збільшувати гучність голосу синтезатора - піднімати занадто тихий голос; нова гучність зберігається так само, як після зміни в кільці налаштувань синтезатора. Типово увімкнено.
    * Збільшувати гучність звуків NVDA - піднімати занадто тихі сигнали і звуки NVDA перед відтворенням звуку додатку, щоб його було чути. Недоступно, коли в налаштуваннях аудіо NVDA гучність звуків NVDA відповідає гучності голосу. Типово увімкнено.
    * Вмикати режим "мовлення" NVDA. Типово увімкнено.
    * Не зменшувати гучність NVDA під час дзвінків - див. "Дзвінки". Типово вимкнено.
    * Повторювати спроби ініціалізувати драйвер синтезатора голосу - запускати синтезатор, якщо він не запустився. Типово увімкнено.
    * Кількість повторних спроб (0 - нескінченна) - скільки разів повторювати спробу, раз на секунду. Доступно, коли спроби повторюються.
* Відтворювати звук, коли аудіо було успішно увімкнено - відтворювати короткий звук після того, як під час запуску NVDA щось було увімкнено. Після команди звук відтворюється завжди. Типово увімкнено.
* Використовувати комбінацію клавіш за замовчуванням - одразу вмикати або вимикати передвстановлену комбінацію NVDA+Windows+Shift+U для команди. Типово вимкнено.

## Внесення змін до вихідного коду додатку
Ви можете клонувати цей репозиторій, щоб внести зміни до NVDA Unmute.

Вимоги:

* [uv](https://docs.astral.sh/uv/) - керує Python та всіма інструментами розробки додатку;
* [GNU Gettext tools](https://mlocati.github.io/articles/gettext-iconv-windows.html) (`msgfmt` і `xgettext` у `PATH`) - компілюють переклади та створюють шаблон рядків для перекладу.

Виконайте такі команди з кореня репозиторію:

1. `uv sync` - встановити залежності для розробки;
2. `uv run prek run --all-files` - запустити всі перевірки коду: лінтинг і форматування за допомогою ruff, перевірку типів за допомогою pyright та інші перевірки;
3. `uv run python -m unittest discover -s tests -v` - запустити модульні тести;
4. `uv run scons` - зібрати додаток, створений файл `.nvda-addon` розміщується в корені репозиторію;
5. `uv run scons pot` - створити файл `.pot` з усіма рядками додатку для перекладу (необов'язково).
